\section{Dasar Teori}
\subsection{Python}
Python merupakan bahasa pemrograman komputer yang biasa dipakai untuk membangun situs, software/aplikasi, mengotomatiskan tugas dan melakukan analisis data. Bahasa pemrograman ini termasuk bahasa tujuan umum. Artinya, ia bisa digunakan untuk membuat berbagai program berbeda, bukan khusus untuk masalah tertentu saja.

Berdasarkan survei pengembang Stack Overflow tahun 2022, Python menjadi bahasa pemrograman terpopuler keempat. Sebanyak hampir 50\% dari responden mengatakan bahwa mereka menggunakan hampir setengah dari waktu kerja mereka dengan menggunakan bahasa pemrograman ini \cite{dicodingPythonPengertian}. 

\subsection{Numpy}
NumPy (Numerical Python) adalah library di Python yang dirancang khusus untuk urusan perhitungan ilmiah. Numpy berisi seperti toolbox yang berisi alat-alat canggih untuk mengolah data, matriks, statistik, hingga aljabar linear \cite{codepolitanNumPyDalam}.

\subsection{Pandas}
Pandas adalah library Python open-source yang menyediakan struktur data (DataFrame) dan alat analisis data yang berkinerja tinggi dan mudah digunakan \cite{ruangguruPandasDefinisi}. Libraries Pandas memiliki format data yang disebut DataFrame, jadi Pandas DataFrame adalah struktur data dua dimensi seperti tabel yang berisi baris dan kolom. Pandas DataFrame berfungsi untuk menyimpan data dalam format grid yang bisa diubah-ubah dengan fleksibilitas yang sangat besar.

Gambaran sederhananya, Pandas DataFrame mirip dengan tabel yang ada di Microsoft Excel. Setiap baris dan kolom akan memiliki label yang bisa digunakan untuk mengakses dan memanipulasi data \cite{digitalskolaPanduanLengkap}.

\subsubsection{Tugas 1}
Buatlah array NumPy 2D berukuran 4×4 berisi angka acak (0–50), kemudian ubah bentuknya menjadi array 2×8 dan tampilkan hanya elemen-elemen yang bernilai lebih dari 25.

\begin{figure}[H]

Array NumPy berukuran \(4 \times 4\) dibuat menggunakan fungsi \(\texttt{np.random.randint(0, 51, size=(4,4))}\), yang menghasilkan bilangan acak dari \(0\) hingga \(50\). Selanjutnya, fungsi \(\texttt{reshape(2,8)}\) digunakan untuk mengubah bentuk array menjadi \(2 \times 8\) tanpa mengubah jumlah elemennya. Terakhir, operasi penyaringan \(\texttt{array\_2x8[array\_2x8 > 25]}\) digunakan untuk menampilkan hanya elemen yang memiliki nilai lebih dari \(25\).

\subsubsection{Tugas 2}
Buatlah dataframe untuk data karyawan yang berisi kolom Nama, Pekerjaan, dan Gaji. Lalu lakukan operasi groupby() pada kolom Pekerjaan dan hitung nilai maksimum, minimum, serta standar deviasi untuk kolom ‘Gaji’ menggunakan agg().

Data karyawan disimpan dalam sebuah \textit{DataFrame} yang memiliki tiga kolom, yaitu \texttt{Nama}, \texttt{Pekerjaan}, dan \texttt{Gaji}. \section{Kesimpulan}
Berdasarkan praktikum yang telah dilakukan, dapat disimpulkan bahwa NumPy dan Pandas adalah library Python yang sangat berguna untuk analisis data. NumPy menyediakan struktur data array yang efisien dan berbagai fungsi untuk manipulasi array, seperti slicing, reshaping, dan operasi matematika. Sementara itu, Pandas menawarkan struktur data DataFrame yang memudahkan pengolahan data tabular, termasuk operasi filtering, grouping, merging, dan pivoting. Dengan memahami kedua library ini, praktikan dapat melakukan analisis data dengan lebih cepat dan efektif.

Berdasarkan tugas yang telah dikerjakan, praktikan dapat membuat array NumPy 2D, mengubah bentuknya, dan melakukan filtering elemen berdasarkan kondisi tertentu. Selain itu, praktikan juga dapat membuat DataFrame untuk data karyawan, melakukan operasi groupby untuk menghitung statistik gaji, serta menggabungkan dua DataFrame menggunakan merge dengan berbagai parameter. Praktikum ini memberikan pemahaman yang lebih baik tentang manipulasi data menggunakan NumPy dan Pandas, yang merupakan keterampilan penting dalam analisis data.
